# RahYar AI Skill: Persian Copy & UX Writing

1. User-facing text is Persian; code identifiers stay English.
2. Short scannable lines.
3. Clear button verbs and stable emoji anchors.
4. Actionable errors.
5. No stack traces, keys, tokens, or raw provider dumps.
6. Consistent status language: آماده / در حال پردازش / موفق / ناموفق.
7. Confirm destructive actions.
8. Paths and branch names in backticks when shown.
9. Professional calm tone.
10. Preserve business meaning while improving clarity.
