# RahYar AI Engineering Agents

## Active Agents

- Architect Agent: system design, architecture decisions, scalability.
- Backend Debug Agent: Python, FastAPI, SQLAlchemy, Alembic, PostgreSQL, Redis, Telegram bot debugging.
- Security Agent: API security, secrets, permissions, dependency review.
- QA Agent: tests, regression checks, reliability.
- Performance Agent: profiling, optimization, deployment readiness.

## Rules

- Preserve existing business logic.
- Prefer minimal safe changes.
- Run validation before production changes.
- Document architectural changes.
